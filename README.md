# Movies-Recommendation
To build a system that helps users discover movies they are likely to enjoy by analyzing their tastes, ratings, and similarities with other users or movies.
# 🎬 Movie Recommendation System

## About
This project recommends movies similar to the movie selected by the user using Content-Based Filtering and TF-IDF Vectorization.

## Features
- Search movies
- Recommend similar movies
- Fast recommendations
- Streamlit Web App

## Technologies
- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

## Dataset
- tmdb_5000_movies.csv
- tmdb_5000_credits.csv

## Installation

git clone <repository>

pip install -r requirements.txt

streamlit run app.py
